# 핀맵 & 배선 규칙

> W2 화·수 "센서 브링업 + 핀맵 문서화"에서 실제 핀 번호를 채워 넣을 문서.
> 지금은 배선 색상 규칙만 먼저 확정해서 W2 조립 전에 참고하도록 한다.
> 실제 핀 배정(GPIO 번호, 타이머 채널 등)은 데이터시트/CubeMX 확인 후 채운다 — 지금은 단정하지 않음.

> **변경 이력 (2026-07-23)**: 원래 자율주행 카(모터+L298N) 배선 계획을 A+C(이상거동 감지
> + 근접경고)로 전환하면서 재작성. 7.4V 모터 전원단, L298N, 모터 제어 배선은 이 프로젝트에서
> 더 이상 등장하지 않는다 (PLAN.md §1 참고 — 해당 부품은 보류).

## 전원 — 단순화됨

모터가 없으므로 **Nucleo는 USB 전원만으로 충분**하다. 배터리(7.4V)/외부 VIN 점퍼 확정
같은 절차가 필요 없어졌다 (원래 있었던 JP5/VIN 관련 결정은 이 계획에서 불필요).

HC-SR04는 5V가 필요한데, Nucleo 헤더에 있는 5V 핀(USB VBUS 유래)에서 바로 공급 가능한지
보드 실물로 확인 — 안 되면 브레드보드 전원모듈(배럴잭 입력)을 별도로 쓴다. 정확한 핀은
W2 화요일에 확정.

W5에서 "휴대용 데모"를 스트레치로 하게 되면 그때 배터리/VIN 조합을 다시 검토한다
(지금은 보류).

## 배선 색상 규칙

| 색 | 용도 | 비고 |
|---|---|---|
| 검정 | GND | 예외 없이 전부. 다른 용도로 쓰지 않는다 |
| 노랑 | 3.3V | Nucleo 3.3V 출력, GY-521 로직 전원 |
| 주황 | 5V | HC-SR04 VCC (Nucleo 5V 핀 또는 브레드보드 전원모듈) |
| 파랑 | I2C SDA | |
| 초록 | I2C SCL | |
| 흰색/회색 | HC-SR04 Trig/Echo 신호 | |

**원칙**: 검정=GND은 절대 다른 용도로 재사용하지 않는다. 점퍼 세트에 정확히 저 색이 다
없을 수 있음 — 부족하면 GND/3.3V/5V부터 확보하고, 신호선은 색이 겹치더라도 라벨 테이프로
구분한다. (색 자체는 전기적 의미가 아니라 순수 참고용 라벨링임 — 안 지켜도 동작엔 문제없음)
