## 1. 원래(자율주행 카) 전체 배선 그림

```
        [18650 ×2 = 7.4V]
               |
        +------+---------------------------+
        |                                  |
   [L298N 모터드라이버]                 (L298N 5V 출력)
        |         ^                        |
   [기어모터 ×2]  | PWM/방향 4~6핀          |
                  |                    [브레드보드 전원레일 5V]
             [Nucleo-F411RE] ------------- 3.3V ---+
                  |  |  |                          |
             I2C  |  |  +-- GPIO ×3 --- [TCRT5000 ×3]  (라인 감지)
                  |  +----- 타이머 IC -- [HC-SR04 ×2]  (거리)
                  +-------- I2C -------- [GY-521/MPU6050] (IMU → AI 입력)
                  |
                 USB(ST-LINK) → PC: 디버깅 + UART printf
```

핵심 원칙: 모터 전원(7.4V)과 로직 전원(3.3V)은 분리하되 GND는 반드시 하나로 묶는다.

배선 색상 (원래 계획의 추가분): 빨강 = 7.4V (배터리 → L298N 모터 전원단),
보라 = 모터 제어 (IN1~IN4, ENA/ENB).

전원 계통 미결이었던 항목: "Nucleo 전원 점퍼(JP5) USB vs VIN 확정",
"L298N 5V-EN과 Nucleo VIN 동시 사용 금지" — 모터가 없어지면서 함께 보류됨.

## 2. 2WD 자동차 키트 (기어모터 + 바퀴 + 섀시) — 매몰 18,140원의 일부

**생김새**: 투명 아크릴 또는 알루미늄 판 1~2장(구멍 다수), 노란 플라스틱 기어박스에
DC 모터가 붙은 **TT 기어모터** 2개, 검은 고무 타이어 2개, 앞쪽에 굴러가는
**캐스터(볼 캐스터/유니버설 휠)** 1개, 나사·너트·구리 스페이서 한 봉지.

**용도**: 차체. 2WD = 두 바퀴만 구동, 나머지는 캐스터. 좌우 바퀴 속도차로 조향
(differential drive) → 별도 조향 서보 불필요.

**활용 포인트**
- TT 모터는 보통 3~6V 정격. 7.4V를 100% 듀티로 물리면 수명이 짧아진다
  → PWM 듀티 상한을 코드에서 걸 것 (예: 70~80%).
- 모터 단자에 리드선이 안 붙은 키트가 많다 → **납땜 필요**. 납땜 후 케이블타이 고정.
- 좌우 모터가 마주보게 장착되므로 "둘 다 전진" = 드라이버 입력은 서로 반대 조합.
- 라인 센서 장착 위치가 주행 성능을 좌우: 앞쪽 최대한 낮게, 바닥에서 3~10mm.

## 3. L298N 모터 드라이버 (PP-A063)

**생김새**: 명함 절반 크기 PCB (색은 벤더마다 다름 — 회로와 무관). 가운데 **커다란
알루미늄 방열판**, 그 아래 검은 L298N 칩. 파란 터미널 블록 3개(OUT1/OUT2, OUT3/OUT4,
+12V/GND/+5V), 점퍼 캡 3개(ENA, ENB, 5V-EN), IN1~IN4 핀헤더.

**실물 식별 체크**
1. 방열판 아래 칩 각인이 `L298N`인가 — 방열판 없는 손톱 크기면 다른 드라이버(L9110S/TB6612FNG/DRV8833)
2. 파란 터미널 블록 3개 + 점퍼 캡 3개 존재 여부
3. ⚠️ 터미널 순서가 벤더마다 뒤집혀 있다 — 실크스크린 글자를 읽고 꽂을 것

**용도**: MCU의 약한 3.3V 신호로 모터의 큰 전류를 스위칭하는 H-브리지 2채널.

**활용 포인트**
- `IN1/IN2` → 모터 A 방향, `ENA` → 속도 PWM. **ENA/ENB 점퍼 캡을 뽑아야** PWM이 들어간다
  (꽂혀 있으면 항상 최대속).
- `5V-EN` 점퍼가 꽂혀 있으면 온보드 레귤레이터가 +5V를 출력(입력 7~12V일 때).
  ⚠️ 외부에서 5V를 넣을 거면 이 점퍼는 뺀다. 동시에 하면 안 된다.
- L298N은 구식 바이폴라 소자라 전압 강하가 1.5~2V — 7.4V를 넣어도 모터엔 5V대.
- 방열판이 뜨거운 건 정상. 손 델 정도면 듀티/부하 의심.
- 가장 흔한 사고: 모터 돌릴 때 MCU 리셋 → §7 브라운아웃 참고.

### PWM 개념 — 디지털로 "세기"를 만드는 법

GPIO는 0/3.3V 두 값뿐인데 "절반 속도"가 필요하다. 해법이 **PWM(펄스 폭 변조)**:
아주 빠르게 껐다 켰다 반복하되 "켜져 있는 시간의 비율(듀티비)"을 조절하면, 관성이 있는
물리 장치(모터)는 깜빡임을 못 따라오고 **평균 전압**으로 반응한다.

```
듀티비 75%:  ▔▔▔▁ ▔▔▔▁ ▔▔▔▁   → 평균 ≈ 0.75 × Vmax → 빠름
듀티비 25%:  ▔▁▁▁ ▔▁▁▁ ▔▁▁▁   → 평균 ≈ 0.25 × Vmax → 느림
```

- 주파수가 너무 낮으면 모터가 떨거나 소리가 남. 적정 범위는 부품별로 다름.
- CS 비유: 아날로그 세기를 시간 영역의 비트스트림으로 인코딩 — 1비트 DAC를 시간으로
  평균 내는 것(델타시그마 변조와 같은 계열).
- STM32에서 PWM은 소프트웨어 delay가 아니라 **하드웨어 타이머**가 만든다: 카운터가
  0→최대값을 돌며 문턱 전엔 핀 켜고 넘으면 끔 — CPU 개입 없음. (타이머 인풋캡처와
  같은 타이머 자원의 다른 모드다: PWM은 파형을 "만들고", 인풋캡처는 "잰다".)

### H 브리지

전류 방향을 바꾸면 모터가 반대로 돈다. 스위치 4개를 H자로 배치해 전류 방향을 뒤집는
회로가 H 브리지고, L298N이 그 칩 구현. MCU 핀은 수 mA뿐인데 모터는 수백 mA~A가
필요하므로 드라이버가 "약한 신호로 강한 전류를 스위칭"하는 중계기 역할을 한다.

## 4. TCRT5000 모듈 ×3 (LM393 + 가변저항) — 라인 트레이싱의 눈

**생김새**: 작은 PCB. 앞쪽에 검-파랑 2색 사각 소자(적외선 LED + 포토트랜지스터),
뒤에 파란 가변저항, LM393 비교기, LED 2개. 핀: VCC, GND, DO, (보통 AO도).

**용도**: 적외선을 바닥에 쏘고 반사량으로 라인 위/밖 판별 (흰 바닥 = 반사 많음).

**활용 포인트**
- 3개를 좌/중/우 배치, 조합으로 조향: 중앙만 검정 → 직진, 좌측 검정 → 좌회전,
  전부 검정 → 교차로/정지선, 전부 흰색 → 라인 이탈.
- **가변저항 캘리브레이션이 전부다.** 실제 트랙·실제 조명에서 출력 LED가 라인 경계에서
  딱 바뀌게 맞춘다.
- 감지 거리 수 mm~1cm대. 바닥에 최대한 가깝게, 긁히지 않게.
- DO만 쓰면 GPIO 3개로 끝. AO를 ADC로 읽으면 PID가 가능해진다.
- 주변광(형광등/햇빛)에 영향받는다. 데이터 수집과 데모를 같은 조명에서.

## 5. 검은 절연 테이프 (다이소) — 구매 취소됨

**용도**: 흰 바닥에 붙여 주행 트랙 제작. 폭 약 18~19mm.

- 3센서 배치 간격을 테이프 폭 기준으로 잡는다.
- 곡률 반경이 너무 작으면 2WD 차동 조향으로 못 따라간다 — 첫 트랙은 완만한 타원.
- 무광 검정이 좋다. 광택 테이프는 각도에 따라 IR을 반사해 센서를 속인다.
- 배경은 흰색/밝은 무광 바닥. 나무 바닥·회색 장판은 대비 부족.

## 6. 18650 전원 계통 (배터리 ×2 + 홀더 + 충전기) — W5 휴대용 데모 스트레치 시 재검토

**18650 배터리 (2600mAh, 보호회로 내장) ×2**
- AA보다 굵고 긴 원통(18×65mm, 보호회로형은 ~70mm). 셀당 공칭 3.7V(만충 4.2V),
  2직렬 = 공칭 7.4V.

**홀더 (오픈형 2구, 직렬)**
- 뚜껑 없음 → **셀을 케이블타이로 고정할 것.** 진동으로 셀이 튀면 순간 전원 차단 →
  MCU 리셋 → 원인 못 찾고 하루 날림.
- 극성 표기를 트레이 바닥에서 확인. 거꾸로 넣으면 보호회로가 막아주지만 믿을 건 아니다.

**충전기 (메가캐논 M2 Plus, 2구)**: 빨강=충전 중, 초록=완충 (모델별 상이).

**취급 규칙**
- 사용 후 홀더에서 셀 분리. 모터가 느려지면 즉시 충전(과방전이 셀을 죽인다).
- 맨 셀을 금속(열쇠/동전)과 함께 두지 말 것 — 외부 단락 → 발열/발화.
- 부풀거나 뜨거워지면 즉시 사용 중단.

**원래 전압 계통 표**
| 레일 | 공급원 | 소비처 |
|---|---|---|
| 7.4V | 18650 ×2 | L298N 모터 출력단 |
| 5V | L298N 5V-EN 레귤레이터 (또는 전원모듈) | HC-SR04, 브레드보드 5V 레일 |
| 3.3V | Nucleo 온보드 레귤레이터 | MPU6050, TCRT5000 로직 |
| GND | 전부 하나로 | 예외 없음 |

## 7. "모터 돌리면 MCU가 리셋된다" — 브라운아웃

큰 부하(모터)가 순간적으로 전류를 확 당기면(기동 전류, inrush) 전원 전압이 푹 꺼지고
(voltage sag), MCU가 동작 최저 전압 아래로 내려가면 **브라운아웃 리셋**이 걸린다.
증상은 "코드가 이상하다"처럼 보이지만 사실 전원 문제다. 대응: 공통 GND 확인,
로직 전원 분리, 굵은 전선.

### 당시의 교훈 (일부는 지금도 유효)

- W2에 모든 부품이 한꺼번에 투입 → 부품 리스크가 W2에 몰린다. 배선은 확정 후 물리적으로 고정할 것.
- GY-521 하나가 W3 전체를 좌우 — 유일하게 대체 불가. (이건 현재 계획에서도 그대로 참)
- W4에 새 부품 없음 — 부품 문제로 W4가 밀리면 W2의 부채가 늦게 청구된 것.
